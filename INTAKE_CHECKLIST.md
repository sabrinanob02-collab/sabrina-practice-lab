# Course and class-meeting intake checklist

Complete this before Claude adds or revises questions.

## Once for each course

- [ ] Confirm the exact course title and professor.
- [ ] Identify the current syllabus and its revision date.
- [ ] Record meeting days/times, exam format if known, exam date, and major deadlines.
- [ ] Identify the authorized textbook/reader edition and distinguish printed from PDF pagination.
- [ ] Inventory posted slides, handouts, Canvas materials, class notes, professor practice questions, rubrics, and model answers.
- [ ] Mark missing materials and intentional page gaps.
- [ ] Record the professor-format evidence as direct, provisional, or unavailable.
- [ ] Add the course and color to `config/app-config.json` and schedule to `config/semester-schedule.json`.
- [ ] Create authority, source, coverage, and theme ledger entries.

## For each new class meeting

- [ ] Date and class/session number.
- [ ] Syllabus topic exactly as assigned.
- [ ] Assigned printed pages and corresponding PDF pages, if different.
- [ ] Rules, statutes, cases, problems, handouts, or Canvas pages assigned.
- [ ] Slide deck filename and posting date, or an explicit note that it is not posted.
- [ ] Class notes or instructor clarifications actually available.
- [ ] New or changed schedule dates and deadlines.
- [ ] Overlap with prior assigned ranges.
- [ ] Intentional gaps and material beyond the cutoff.
- [ ] Existing questions covering the same doctrine.
- [ ] Prior exams/questions to blacklist for factual originality.
- [ ] New theme checked against `authoring/ledgers/themes.json`.
- [ ] Planned question count, topics, difficulty, and answer-letter plan.
- [ ] Source and coverage ledgers updated before drafting.
- [ ] `npm run verify` passed after import.
- [ ] Local preview checked before any authorized publication.

## Before publishing

- [ ] Student expressly authorized publication.
- [ ] No source documents or authenticated links entered the project.
- [ ] No rule numbers or named authorities leak into question-facing text when they telegraph the issue.
- [ ] No duplicate IDs or copied factual engines.
- [ ] Answer positions are balanced and non-mechanical.
- [ ] `_site` contains only the public whitelist.
- [ ] Coverage report states missing slides, excluded pages, and other limitations candidly.
