## First-time GitHub setup

```text
Walk me through putting this Law School Practice Lab online with a free GitHub account and GitHub Pages. Assume I have not used GitHub before. First read README.md, CLAUDE.md, and docs/GITHUB_PAGES.md. Explain one small step at a time and pause whenever I must personally create an account, verify email, sign in, approve the GitHub connector, or enable two-factor authentication. Never ask me to paste a password, two-factor code, recovery code, token, or cookie into chat. After I connect GitHub, create a public repository for the app, but confirm before uploading that sources/, node_modules/, _site/, credentials, private paths, and authenticated links are excluded. Run the full verification, configure GitHub Pages through the included workflow, wait for deployment, verify the live app, and give me the exact website address. Do not publish until I expressly approve the final upload.
```
